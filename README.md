# Personal Portfolio
Website portofolio personal dengan desain modern, minimalis, dan responsif.

## Features
* Modern dark / glassmorphism UI
* Responsive untuk desktop & mobile
* Profile dan developer statistics
* Social media links
* Copy link dengan satu klik
* Animasi ringan
* Tanpa framework atau backend

## Tech Stack
* HTML5
* CSS3
* JavaScript

## Penggunaan
Clone repository lalu buka index.html di browser.
